# MeuSal-rio
Vou iniciar meu primeiro emprego e me deparei com uma pergunta: como vou organizar meu salário?  Foi a partir dessa dúvida que surgiu a ideia do MeuSalário, um site criado para facilitar a organização financeira. Nele, é possível acompanhar gastos, definir metas, organizar o salário e analisar investimentos em um só lugar.
